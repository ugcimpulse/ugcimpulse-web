# UGC Impulse · web

Web estática de [ugcimpulse.com](https://ugcimpulse.com), publicada en Hostinger desde la rama `main`.

- `index.html` — página principal (pop-up creador/marca, servicios, red, formularios)
- `academia.html` — curso UGC y planes
- `styles.css` — estilos compartidos

Los enlaces de reservas y pago, el email y los datos opcionales (cifras, logos, equipo, reseñas) se cambian en el bloque `CONFIG` al final de cada página.
