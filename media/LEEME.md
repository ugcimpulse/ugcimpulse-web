# Cómo cambiar las imágenes y vídeos de la web

Sube los archivos a estas carpetas **con el nombre exacto** de la tabla. La web los detecta sola:
si un archivo existe se muestra; si no, sigue saliendo la ilustración. Para cambiar uno,
sube otro con el mismo nombre (sustituye al anterior).

## Cómo subir un archivo desde el navegador
1. Entra en github.com/ugcimpulse/ugcimpulse-web y abre la carpeta (por ejemplo `media/videos`).
2. Pulsa **Add file → Upload files** y arrastra el archivo (ya con su nombre correcto).
3. Abajo pulsa **Commit changes**. En 1-2 minutos está publicado en ugcimpulse.com.

Para borrar uno: ábrelo en GitHub, menú **⋯ → Delete file → Commit changes**.

## Vídeos — carpeta `media/videos/`
Formato **MP4 vertical (9:16)**, idealmente 720×1280, de menos de 10 MB (mejor 2-5 MB).
Opcional: una portada con el mismo número en **JPG** (`video-01.jpg`) para que cargue más rápido.

## Logos de marcas clientes — carpeta `media/logos/`
`logo-01.png` hasta `logo-12.png`. **PNG con fondo transparente**, unos 400 px de ancho.
La sección "Marcas que confían en nosotros" aparece sola en cuanto hay al menos uno.
Solo logos de marcas con las que hayas trabajado de verdad.

## Portada de la academia — carpeta `media/academia/`
`portada.jpg`: foto vertical (4:5), unos 1000×1250 px. Sustituye a la ilustración de la academia.

## Límites
- GitHub no admite archivos de más de 100 MB. Un vídeo UGC de 30-60 s comprimido pesa mucho menos.
- No subas los archivos por el Administrador de archivos de Hostinger: la siguiente publicación desde GitHub los borraría.
